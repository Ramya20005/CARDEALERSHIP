
## Project Overview
This is a simple car dealership web application that allows users to browse available cars, view details, and interact with a user-friendly interface. The project demonstrates basic web development skills using HTML, CSS, and JavaScript.

## Features
- Browse a list of available cars with images and details
- Search and filter cars by model, price, or other criteria
- Interactive UI for selecting and viewing car details
- Responsive design for desktop and mobile devices
- Custom styling for a modern look

## Installation
1. Download or clone this repository to your local machine.
2. Ensure all files (`index.html`, `script.js`, `style.css`) are in the same directory.
3. No additional dependencies are required.

## Usage
1. Open `index.html` in your web browser.
2. Use the interface to browse, search, and view cars.
3. All features are available offline; no server setup is needed.

## Technologies Used
- HTML5: Structure of the web page
- CSS3: Styling and layout
- JavaScript: Interactive functionality

## File Structure
- `index.html`: Main HTML file for the website
- `script.js`: JavaScript file containing the logic for the website
- `style.css`: CSS file for styling the website
